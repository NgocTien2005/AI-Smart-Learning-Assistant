# Data and compatibility
No schema or migration changes. Lesson.documentUrl retains legacy basename; new remote identity supabase:<configured-bucket>/lumina/<uuid>.<ext>. Display name/documentText/hash/revision unchanged. Existing reset hash/expiry/cooldown/authVersion unchanged. Switching provider affects new writes only, never routes an old basename to remote. Wrong configured remote bucket is unavailable, not another bucket search. Existing local documents require separately planned migration; this feature never mutates them automatically. Unknown DB commit may leave orphan, explicit conflict can clean the known loser. Backend secrets/config are not persisted in application tables.
